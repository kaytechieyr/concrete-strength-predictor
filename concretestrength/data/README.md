# Dataset

Project menggunakan **Concrete Compressive Strength** dari UCI Machine Learning Repository.

- DOI: https://doi.org/10.24432/C5PK67
- Lisensi: CC BY 4.0
- Data asli: 1.030 baris
- Data setelah menghapus 25 duplikat identik: 1.005 baris
- Nilai kosong: tidak ada

## Atribut

| Kolom | Arti | Satuan |
|---|---|---|
| Cement | Kandungan semen | kg/m³ |
| Blast Furnace Slag | Kandungan slag | kg/m³ |
| Fly Ash | Kandungan abu terbang | kg/m³ |
| Water | Kandungan air | kg/m³ |
| Superplasticizer | Kandungan bahan tambah | kg/m³ |
| Coarse Aggregate | Agregat kasar | kg/m³ |
| Fine Aggregate | Agregat halus | kg/m³ |
| Age | Umur beton saat diuji | hari |
| Concrete compressive strength | Kuat tekan beton | MPa |

Dataset ini tidak memuat lokasi proyek, mutu rencana, metode curing, atau kondisi lingkungan. Karena itu, model hanya mempelajari hubungan dari delapan atribut yang tersedia.
